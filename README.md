# Daily Journal Application

## Project Description
The Daily Journal Application is a simple Python-based project that allows users to write and save their daily activities, learning experiences, moods, and goals.

This project is developed as part of HCL Python Training to understand basic Python programming and file handling.

## Objective
The main objective of this project is to create a simple application where users can maintain their daily journal and read their previous entries.

## Features
- Create a new daily journal entry.
- Enter the date and daily activities.
- Record what you learned.
- Save your mood and tomorrow's goal.
- Save journal entries in a text file.
- Read previously saved journal entries.

## Technologies Used
- **Language:** Python
- **Platform:** Google Colab / Python IDLE / VS Code
- **File Storage:** Text File (.txt)

## Python Concepts Used
1. **Variables:** Store user information.
2. **input():** Take information from the user.
3. **print():** Display messages and journal entries.
4. **Functions:** Organize the program into simple tasks.
5. **File Handling:** Save and read journal entries.
6. **Conditional Statements:** Allow users to choose different options.
7. **Loops:** Display the menu until the user exits.

## How the Application Works
1. Run the Python program.
2. Select an option from the menu.
3. Choose to create or read a journal entry.
4. Enter the required details.
5. The application saves the entry in a text file.
6. Previous entries can be viewed anytime while the file is available.

## Sample Journal Entry

**Date:** 20-11-2026

**Today's Activity:** Attended HCL Python training

**What I Learned:** Python file handling and basics of Pandas

**Mood:** Happy

**Tomorrow's Goal:** Practice Python and learn more

## How to Run
1. Open Google Colab or any Python editor.
2. Copy and paste the Python code.
3. Run the program.
4. Choose an option from the displayed menu.
5. Enter your daily journal details.

**Note:** In Google Colab, download the saved text file if you want to keep your journal permanently.
